# Link Flame brand assets

The leaf-flame: a square plate of Moss ink with a single leaf cut out of it in
paper, its tip rising and hooking into a flame, with a thin midrib slit up its
centre. One silhouette that is a leaf and a flame at once — "Link Flame",
everyday essentials minus the plastic. The rationale and the path live in
`components/brand/Logo.tsx`.

Every file here is generated by `npm run brand:generate`
(`scripts/generate-brand.mjs`) from one path. Edit the script, not the files.

## Files

| File                                             | What                                                                           |
| ------------------------------------------------ | ------------------------------------------------------------------------------ |
| `mark.svg`                                       | The mark, Moss `#456336`, 24×24 viewBox. The leaf is a transparent hole.       |
| `mark-dark.svg`                                  | The mark for night grounds, Moss `#abc99c`.                                    |
| `mark-mono.svg`                                  | Single-colour `#000` for engraving, one-ink print, monochrome contexts.        |
| `logo-horizontal.svg` / `-dark.svg`              | Mark, 12px gap, wordmark; mark height = the wordmark's cap height.             |
| `logo-stacked.svg` / `-dark.svg`                 | Mark above, 12px gap, wordmark centred beneath at half the mark's height.      |
| `../icon.svg`                                    | The favicon form: the leaf filled paper so it reads on light and dark tabs.    |
| `../favicon.ico`, `../favicon-{16x16,32x32}.png` | Rasters of the favicon form (the .ico holds 16, 32 and 48).                    |
| `../apple-touch-icon.png`                        | 180px, mark on paper with 12% padding, no transparency.                        |
| `../android-chrome-{192x192,512x512}.png`        | Mark on paper, 12% padding.                                                    |
| `../android-chrome-512x512-maskable.png`         | 22% padding, inside the maskable safe zone.                                    |
| `../og.png`                                      | 1200×630 share image: mark, wordmark and the kicker on paper.                  |
| `../../docs/brand/lockups.png`                   | A 2x contact sheet of the mark at 16/32/88 and both lockups, by day and night. |

The lockup SVGs have the wordmark converted to outlines (Fraunces 700) and
reference no font. In the app use `<Logo>` / `<LogoMark>` from
`components/brand/Logo.tsx` instead; the wordmark there is live text and the
mark takes its ink from the theme (`hsl(var(--primary))`).

## Rules

- **Sizes.** The mark is 1:1 on a 24-unit grid. The lockups are drawn at
  mark = 96 units.
- **Clear space** around the mark or any lockup is 0.44 × the mark's height,
  on every side.
- **Minimum size.** 16px for the mark alone, 96px wide for either lockup.
  Below that use the mark.
- **Colours.** Moss `#456336` on paper `#f9f8f5`; Moss `#abc99c` on night
  `#111317`; the wordmark in Ink `#1a1f23` / `#fafafa` with "Flame" in the
  Moss of the ground. Monochrome: `mark-mono.svg`.
- **Do not** rotate, recolour, add shadows or gradients, round the corners,
  outline the plate, stretch the mark, flip the leaf, or set the wordmark in
  another face.

## Regenerating

```sh
npm run brand:generate
```

Edit `MARK_PATH` in both `components/brand/Logo.tsx` and
`scripts/generate-brand.mjs` (the unit test fails when they drift), run the
script, look at `docs/brand/lockups.png` and the favicons, and commit the
output. The script is deterministic: a second run leaves `git status` clean.
